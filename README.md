## What this repository does

Unsupervised anomaly detection on DALTON **H1 kitchen sensor 41**, using:

1. An **LSTM Autoencoder** with 15,242 trainable parameters on 60-second × 10-feature sequences.
2. **Isolation Forest** trained on 40 per-window statistical features (mean, standard deviation, minimum, maximum).
3. Chronological **training dates** May 28–30, **validation** May 31, and **test** June 4–5 (2023).
4. A **99th-percentile validation score threshold** for each model.
5. Controlled synthetic perturbations (spikes, shifts, noise), and qualitative inspection of real detections and activity annotations.

The recorded model comparisons are **not verified real-world anomaly accuracy**, because DALTON's human-activity annotations are not binary anomaly labels. Original test windows are assumed normal in the controlled synthetic evaluation even though some may naturally be unusual.

## Run in Google Colab

1. Open [`notebooks/IAQ_Anomaly_Detection_Reproducible.ipynb`](notebooks/IAQ_Anomaly_Detection_Reproducible.ipynb) in Google Colab.
2. Select **Runtime → Change runtime type → T4 GPU** if available.
3. Run all cells in order. The notebook installs `git-lfs` if necessary and retrieves **only six selected DALTON CSVs** and the annotations. It does not depend on any earlier friend's code.
4. The notebook fits scalers using **training data only** and never creates windows across filtered data gaps.
5. Training creates the LSTM model checkpoint at `/content/IAQ_Anomaly_Detection/models/best_iaq_lstm_autoencoder.keras`. Download and preserve it; Colab `/content` is temporary.

A new training run may not reproduce identical numbers from the earlier session due to random initialization and numerical differences. The previously trained independent checkpoint was not available in this workspace.

## Previous run — recorded results

| Metric | Isolation Forest | LSTM Autoencoder |
| --- | ---: | ---: |
| **Controlled synthetic accuracy** | 64.53% | 96.80% |
| **Controlled synthetic precision** | 95.46% | 93.98% |
| **Controlled synthetic recall** | 30.50% | 100.00% |
| **Controlled synthetic F1** | 46.23% | 96.90% |
| Flagged real test windows | 2,251 (1.30%) | 11,623 (6.74%) |

The test contains **172,564** overlapping 60-second sequences; the LSTM flags were grouped into **23** contiguous events. 27 of 165 activity annotations had a flagged sequence within ±5 minutes. The largest average feature-wise share of reconstruction MSE in flagged windows was **humidity (37.42%)**.

The comparison used 2,000 unfiltered, largely non-overlapping original test windows provisionally labeled normal plus 2,000 corresponding modified copies labeled synthetic anomalous; injected distortions were relatively large. **Do not use these metrics as claims of real-world classification accuracy.** Previous results were reported from Colab output and preserved in [`results/reported_reference_metrics.json`](results/reported_reference_metrics.json), not freshly verified against a saved independent model checkpoint here.
